# Driver Monitoring System Example

This example shows how AITRT can be applied to an automotive Driver Monitoring System without changing the canonical taxonomy.

A DMS assessment can link operational scenarios to canonical risks; risks to trust dimensions such as safety, fairness, privacy, reliability, and human oversight; controls to measurable KPIs; and evidence artifacts to an assessment record.

This example is descriptive and does not define a regulatory compliance conclusion for a particular DMS.
